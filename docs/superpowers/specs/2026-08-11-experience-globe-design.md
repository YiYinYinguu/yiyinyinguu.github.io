# Experience 地球设计

日期：2026-08-11
状态：三种摆法在原型上比过，逐项确认

## 背景

Experience 底下原来垫的是 `public/images/world.svg`——等距圆柱投影的平面世界地图，
五个城市按经纬度落点，悬停条目时点亮并拉一条虚线过去。

Routes 那边已经换成了 d3-geo 正射投影的真球面。两处都在讲「去过哪儿」，
底图却是两套投影、两种语言。这次把 Experience 也换成球，并且让它跟着滚动转。

## 动作从哪来

**滚到哪一条，球就转到那座城。**

不是匀速自转，也不是把滚动量线性映射到转角——那两种换成任何一个转圈的东西都成立。
经历列表本身就是一条地理迁移线，球的每一次转动都对应一条真实的经历，
这是「地球」这个选择唯一站得住的理由。

判定「在读哪一条」用 IntersectionObserver，视窗上下各切掉 45%，只剩正中一条带子；
行比带子矮的时候带子里会同时有两条，取列表里靠前的那条，否则往回滚会在两座城之间反复横跳。
没用 scroll 回调：那个每帧都要自己算位置，而这里只在越线时响一下。

悬停优先于滚动：手放上去了就是在问这一条，不管页面滚到哪儿。

### 转的手感

| 决定 | 值 | 理由 |
|---|---|---|
| 纬度只跟一部分 | `TILT = 0.55` | 整跟会上下猛甩；完全不跟就看不出维也纳在北、新加坡在赤道 |
| 缓动 | 指数逼近，`TAU = 320ms` | 跟帧率无关：掉帧时步子自动变大，不会慢半拍 |
| 经度走最短弧 | 差值归一到 ±180 | 维也纳到新加坡该往东转 87°，不是往西转 273° |
| 到位就停 | `SETTLED = 0.05` | 不空转 rAF |
| `prefers-reduced-motion` | 直接跳过去 | 一个人是因为动画不舒服才开的这个开关，背景更没理由动 |

列表是**倒序**的（Vienna 在最上，Alibaba 在最底），所以往下滚是在往回走时间线。
球跟的是你正在读的那一条，不是时间顺序——这是刻意的，读到哪儿球就在哪儿。

## 摆法

比过三种：满幅居中大球 / 右侧出血半球 / 角落 sticky 小球。**选满幅居中**。

右侧那版会跟机构 logo 抢位置；角落小球太小，城市名都放不下，它跟经历列表的关系弱到
只剩「有个球在转」。满幅那版球心就在列表正中，当前那座城转到正面，
点落在你正在读的那几行附近——虚线因此很短。

球径 `FILL = 0.7`，占较短那一边的七成。吃满（1.0）时球顶球底都顶到列表的上下边，
像一个要挤出去的东西；收到 0.5 又太小，跟「垫在底下的世界」不像了。

## 视觉

这颗球是**背景**，Routes 那颗是**主角**，两者的取舍反过来：

| | Routes 的球 | Experience 的球 |
|---|---|---|
| 海 | 径向渐变 + 球面阴影 | 平色 `#eaeff2` |
| 海岸线 | 主色淡版 `#e5c2c4` | 中性灰 `#dfe5e9` |
| 九段线 | `#d09a9e` | `#d3dbe1` |
| 整层 | 不透明 | `opacity 0.55` |
| 交互 | 拖拽、缩放、自转开关 | 无，唯一的输入是你滚到了哪儿 |

渐变让球有体积感，而体积感在背景里是往前站的：球一有明暗，眼睛就先看球再看字。
海岸线同理，一红就跟条目抢注意力。**球上唯一的红是城市点**。

城市点常态 r=5，当前那座城 r=8。只给当前那座城写名字——六个名字常驻会跟正文抢注意力。

## 连线

从行的右侧拉一条虚线到球上那个点，悬停时才画。

- 起点 `row.right - 120`：logo 宽 100 加上行的 `px-3`，退到这里就贴着标志左边缘，
  既不压上去也不空出一截。
- 终点 `dot.right + 3`：停在红点右边缘外一点，不拉到点心——压过去的话点就不是一个完整的圆了。
- 城市名写在点的**左**边（`text-anchor="end"`）：虚线从右边过来，名字放右边会被穿过去。
- `data-pin` 打在圆点上而不是整组 `<g>` 上：连线量的是这个属性的包围盒，
  打在组上的话盒子里连城市名一起算，线会歪到名字那边去。
- 球在转，点每帧都在挪，所以连线也每帧重算。只在悬停时跑这个循环。
- 转到背面的点是 `display:none`，量出来是零尺寸的框——这种情况下不画线，
  否则会指到容器左上角。用 `display` 而不是 `opacity:0` 正是为了这个判断。

## 实现

- `components/sections/ExperienceGlobe.tsx`——球本身。每帧只改属性、不动节点，
  理由和 `components/routes/Globe.tsx` 一样。
- `components/sections/EducationExperience.tsx`——拥有列表、滚动判定和连线。
  球只接收「当前是哪座城」，不知道有滚动这回事。
- 陆地数据复用 Routes 的 `public/routes/land.json`，没有新增资源。
- `components/sections/ExperienceMap.tsx` 和它的 `public/images/world.svg` 就此退役。

## 没做的

- 不给背景球加拖拽和缩放。它不是用来查的，是用来看的；能拖的东西会邀请人去拖，
  然后发现拖了也没有别的可看。
- 不做移动端的特别处理。球是绝对定位垫在条目底下的，窄屏时半径跟着容器缩，
  文字仍然压在上面读得清。
